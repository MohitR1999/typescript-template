# Typescript boilerplate
A simple boilerplate for your simple typescript applications. Configured with Typescript compiler, hot reload, and jest for Test Driven Development (TDD)

## Steps to run
1. Since this is a template repository, create your own repo using this template.
2. Navigate to the project root, run `npm install` to install all the dependencies.
3. Run `npm test` to run the existing tests to confirm everything works.
4. Build something interesting :)
